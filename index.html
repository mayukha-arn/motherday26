Add it to your browser

A kawaii version of us that waves from the corner of every page you visit. Takes about 2 minutes to set up.

1

Download the three extension files

Right-click each file below and choose Save link as. Save all three into a new folder on your Desktop called motherday26.

📄 manifest.json ↓ save 📄 content.js ↓ save 📄 content.css ↓ save
Make sure all three files end up in the same folder and keep their exact names.
2

Check your folder

Your motherday26 folder should contain exactly these three files:

  • manifest.json
  • content.js
  • content.css
Do not move files out of the folder — Chrome needs all three in the same place.
3

Open Chrome's extension settings

In Chrome, type this into the address bar and press Enter:

🔗
chrome://extensions

This opens the Extensions page where you manage everything installed in your browser.

4

Turn on Developer Mode

In the top-right corner of the Extensions page, you will see a toggle labeled Developer mode. Flip it on. A few new buttons will appear at the top left.

This is safe — it just lets you load extensions from your own computer instead of the Chrome Web Store.
5

Load the folder

Click the Load unpacked button that appeared. A file picker will open. Navigate to and select the motherday26 folder itself — not a file inside it, the whole folder. Click Select.

  • You should now see "Little Buddy" appear as an installed extension.
6

Open any website

Go to any page — Google, Wikipedia, a news site. Look at the top-right corner of the page. You should see us bobbing and sending hearts. 💕

It will not appear on Chrome's own pages like the new tab page — that is normal. Try any real website.
✦

Something not working?

Go back to chrome://extensions, find Little Buddy, and click the refresh icon (↺). Then close and reopen the tab you want to see it on. Existing tabs need to be refreshed after installing.
